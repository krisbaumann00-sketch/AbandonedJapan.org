# FighterZ Coach

A personal training coach for Dragon Ball FighterZ (built with the Switch 2 version in mind).

- `index.html` – open in any browser. Progress saves in that browser (use Sets → Backup to copy it out).
- `coach.html` – the same page, as published to claude.ai (no document skeleton).

## What's inside
- **Today** – a daily session (30/60/90 min) built from your phase and your most common loss reasons.
- **Drills** – 33 drills (execution, movement, defense, offense, neutral, team/meter, review) with training-mode setup, steps and a pass mark. Log reps to track success rate.
- **Path** – 5 phases (Foundation → Execution → Defense → Offense & Team → Competition) with 30 milestones.
- **Sets** – log every set, tag why you lost; the top tag drives tomorrow's focus.
- **Combos** – team, assists, routes in numpad notation, and 10-in-a-row streaks.
- **Guide** – notation, universal mechanics, team building, neutral/offense/defense, training mode setup, Switch 2 notes, path to pro, pros to study.

Inputs listed are default shortcuts; your in-game Command List is the final word.
